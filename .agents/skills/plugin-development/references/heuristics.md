# Heuristics
- **In detector-regex SPECS, equal-span overlap ties resolve by list order: place more specific kinds before looser shapes that also match the same text (ssn, credit_card, and us_bank_routing before phone).**: When adding or reordering entity patterns in crates/detector-regex/src/patterns.rs (from trace 1)
- **Validate a candidate detector regex against real-shaped positive and negative fixtures before wiring it in: alternation branches sharing a prefix can truncate a longer form, and a global \b wrapper breaks branches that start or end with ':'.**: When adding or changing alternation-heavy detector patterns such as IPv6 (from trace 1)
- **Assert every alternation branch against its real-world form; a branch that cannot match it is dead weight (OpenPGP armor is `BEGIN PGP PRIVATE KEY BLOCK`, a space-separated `Bearer <token>` carries no `:` or `=`).**: When adding layered credential patterns to detector-regex (from the 2026-09-19 private-key/`Bearer`/`ENCRYPTED` hardening)
